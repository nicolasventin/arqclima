Excel / CSV Revisa hojas, encabezados y filas automáticamente. Si el proveedor usa nombres de columna raros o una planilla tipo catálogo con varias subtablas, se completa con IA.
Word Lee tablas y listas tabuladas localmente; si no hay ninguna tabla interpretable, se completa con IA. También conserva imágenes embebidas.
PDF Extrae tablas de texto localmente; si no hay texto (escaneado) o no hay tabla reconocible, se completa con IA. Puede requerir revisión.
Foto de lista Una foto de una lista de precios se lee siempre con IA. Las imágenes embebidas en otros formatos se muestran como evidencia, pero nunca identifican un producto por sí solas.
Seguridad: un PDF escaneado sin texto no se interpreta con OCR automático. Se conservan sus imágenes para revisión, evitando convertir una lectura dudosa en precios reales. Cualquier producto extraído con IA (marcado "(IA)" en el origen) nace con confianza media y destildado: nunca se aplica al catálogo sin revisión humana.
